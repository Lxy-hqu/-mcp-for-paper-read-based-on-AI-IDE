## 自己复测

核心测试只需要 Python；PDF合成场景使用 reportlab，pypdf提供后备提取，Poppler用于版面提取测试。若本机缺少可选能力，测试会明确跳过对应场景，不能把跳过说成通过。

```bash
python -m pip install reportlab pypdf
python -m unittest discover -s tests -v
python tests/run_validation.py
```

Windows 可从测试环境提供 Poppler；Linux 可使用系统包管理器安装 `poppler-utils`。不要仅安装 Python PDF 库就假定已有页面渲染工具。

包与安装检查可在独立 Codex 用户目录运行，避免修改日常技能：

```bash
python tools/install_skill.py --codex-home ./validation/codex-home
python tools/final_audit.py
```

`validation/` 与 `dist/` 为本机生成目录，包含运行信息，不提交仓库。包审核检查哈希、内部链接、语法及安装后的实际命令；不证明所有科学判断正确。
