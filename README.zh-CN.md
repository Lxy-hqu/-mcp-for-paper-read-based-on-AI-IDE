## 读完论文，应该留下自己的判断

这个技能围绕四件事组织阅读：**作者提出了什么、方法为什么这样设计、实验究竟支持什么，以及自己的项目该怎样验证借鉴的想法。**

Codex 负责理解与分析；本地脚本负责保留逐页文本和位置、存储证据、检查引用与记录讨论。它会区分两个结果：分析材料是否完成，以及用户是否实际表现出理解。用户没有回答的问题保持“未验证”，不会因为报告很长或用户说“懂了”就自动判为掌握。

## 可以获得什么

| 模块 | 产出 |
|---|---|
| 连贯精读 | 问题→假设→设计→实验→结论，学术版与通俗版解释 |
| 数学与机制 | 符号、形状、假设、推导、小例子和解析限制 |
| 图表与证据 | 关键判断对应原文页码、图表或公式，区分观察和推断 |
| 写作素材 | 专业术语、搭配、句式与段落结构，保留适用条件和论断强度 |
| 方法迁移 | 对比维持基线、低成本借鉴、探索性改造，给出最小实验及放弃条件 |
| 多论文综合 | 比较前提与评价条件，保留真实分歧，避免跨数据集直接排名 |
| 研究讨论 | 预测、解释、反证、修正，记录真实回答、提示与答案暴露 |
| 知识管理 | SQLite 检索、Markdown/JSON 导出、断点续读与后续材料附加 |

理论、实证、工程及机器学习论文采用不同分析重点；适用时生成算法或复现代码，不把所有研究都套成神经网络。

## 快速开始

需要 **Python 3.10+**、可访问本地文件和工具的 Codex 环境。以下克隆命令还需要 Git。使用技能不要求安装原 MCP、Node.js 或 Ollama，也不需要另配模型 API 密钥。

```bash
git clone https://github.com/Lxy-hqu/-mcp-for-paper-read-based-on-AI-IDE.git paper-research-mentor
cd paper-research-mentor
python tools/install_skill.py
```

安装脚本将技能复制到 `$CODEX_HOME/skills/paper-research-mentor`；未设置时使用 `~/.codex/skills/paper-research-mentor`。它会核对哈希、备份不同的已有版本，并在 `dist/` 生成可分发 ZIP。论文和阅读数据库不会放入安装包。

在 Codex 附上论文后输入：

```text
使用 $paper-research-mentor 深读这篇论文。
保存完整分析、关键公式与实验解释、写作素材及方法建议，
随后和我讨论最值得深入思考的问题。
```

暂时不想互动时：

```text
使用 $paper-research-mentor 自动完成全部分析，不要向我提问。
把思考题单独保存，我的理解状态保持未验证。
```

技能允许自动匹配精读请求；明确写名称更便于指定。新安装后若列表尚未显示，可重新打开聊天或重启 Codex。

## 从论文走向自己的项目

```text
用 $paper-research-mentor 比较这些论文，并结合当前项目的 README、
数据说明和实验配置，判断哪些机制值得借鉴。
对比保持基线、低成本改变和较大探索；
每个建议都给出最小验证实验，以及什么结果会让我们放弃它。
```

没有项目资料时只给条件化方向，不编造项目事实。讨论时一次聚焦一至两个问题；用户可以跳过或直接要解释。提示、答案暴露与后续修正会保留，不冒充独立理解。阅读请求也不会自动触发项目改动或长时间训练。

## 一个具体的阅读结果

在 *Attention Is All You Need* 的 arXiv v7 示例中，阅读记录会：

- 保留表2的 EN-FR **41.8** 与同页正文 **41.0** 的不一致，标为待核对。
- 区分训练时的位置并行与生成时的自回归依赖。
- 将注意力图视为展示性证据，而不直接证明因果解释。
- 将没有实际回答的三个思考节点保留为 `pending / unverified`。

## 验证与边界

已记录的完整本地运行通过 **36 项自动测试**，另完成真实论文全篇试用与独立审核。测试检查证据、版本、元数据更正、讨论状态、后续材料、导出和安装；不等于自动证明科学解释或教学效果正确。

核心存储使用 Python 标准库与 SQLite。PDF 提取优先使用 Poppler，pypdf 可作后备；页面渲染、OCR 和符号结构分析按能力检测并明确降级。

真实 OCR 质量、安装 SymPy 后的可选分支、真实 Ollama 推理，以及完整 WMT/BLEU 复现尚未在该记录中验证；没有进行真实学习者的成效实验。文档与代码中会区分代码骨架、教学计算和科学结果复现。

本地文件处理不代表 Codex 模型完全离线；发给宿主模型的材料仍受该宿主的处理方式约束。
